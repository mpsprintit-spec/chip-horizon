# Web Audit Suite V0.1

**Date:** 2026-10-06  
**Web laboratory:** STWF Visual Laboratory v0.6

## Purpose

This suite verifies software behavior that can be checked without claiming physical validation.

The test categories are deliberately separated:

1. **Known-answer test** — runtime output is compared against fixed reference values.
2. **Boundary tests** — selected limiting values are checked.
3. **Reset test** — state variables must return to the declared initial state.
4. **Trace export** — the observed software state can be exported for independent inspection.

## Known-answer case

Input:

`X=[3,5,2,7]`

Initial state:

`S_0=0`

Contract:

`S_(n+1)=S_n+X_n`

Fixed reference:

`[3,8,10,17]`

The reference vector is written explicitly and is not generated by the test's runtime recurrence.

PASS requires RMS error < 1e-9 and maximum absolute error < 1e-9.

## Boundary cases

- zero input: 0 + 0 + 0 = 0
- signed input: 10 - 3 + 2 - 4 = 5
- retention lambda = 0: next state ignores prior state
- retention lambda = 1: prior state is fully retained for the tested step
- reset: time, field state and five state nodes return to zero
- reference vector reproduces [3,8,10,17]

## Trace export

The browser can export:

`stwf_web_trace_v0_6.json`

The export contains:

- laboratory version;
- timestamp;
- mode;
- current parameter values;
- time step;
- state vector;
- field state;
- field history;
- computation-test trace.

This allows a reviewer to inspect the values without trusting the visual rendering alone.

## Important limitation

This suite is **software verification**, not physical validation.

A PASS does not demonstrate:

- physical wave propagation;
- material state retention;
- physical interference;
- energy efficiency;
- computational advantage;
- chip operation.

## Required future layer

The next serious step is an independent reference implementation outside the browser, followed by comparison of browser output against that reference. After that, physical validation requires measured observables rather than browser-rendered quantities.
