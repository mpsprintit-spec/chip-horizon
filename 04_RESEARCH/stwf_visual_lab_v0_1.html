STWF VISUAL LABORATORY v0.3 — resonance / state / feedback model

Experiment mode
Physical abstraction:
INPUT → WAVE FIELD → INTERFERENCE → STATE → FEEDBACK → WAVE FIELD

Resonance menyimpan sebagian energi/state. Feedback mengembalikan state ke medan pada langkah berikutnya. Threshold hanya model nonlinier sederhana.

Ini simulator matematis/visual, bukan solver elektromagnetik dan bukan hasil pengukuran material. Parameter bukan spesifikasi perangkat fisik.
