# FAILED APPROACHES / REJECTED ASSUMPTIONS

1. Optical computation is free — ditolak. Source, modulation, detection, memory, control, conversion, amplification, dan correction tetap membutuhkan energi.

2. Interference alone is universal — ditolak. Linear interference bagus untuk linear transformation, tetapi nonlinear/state mechanisms diperlukan untuk threshold, branching, memory, dan general computation.

3. Reversible means zero energy — ditolak. Device nyata memiliki loss, noise, leakage, control overhead, dan finite precision.

4. Asynchronous automatically saves energy — ditolak. Event-driven dapat mengurangi global switching tertentu, tetapi event generation, detection, routing, dan control tetap memiliki biaya.

5. Full connectivity — ditolak sebagai strategi scaling karena connection count cenderung tumbuh kuadratik.

6. Persistent state is always beneficial — ditolak. State lama dapat menjadi contamination dan membutuhkan lifecycle.

7. More physical parallelism always means faster — ditolak. Readout, routing, encoding, memory, synchronization, dan I/O dapat menjadi bottleneck.

8. STWF automatically beats CPU/GPU — ditolak. Tidak ada superiority claim sebelum benchmark end-to-end.
