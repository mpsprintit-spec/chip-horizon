# Physical Stateful Cell Calibration V0.1

Status: numerical calibration only.

## Purpose

Before sweeping physical non-idealities, the simulator must demonstrate that its ideal parameterization can reproduce the target state update:

\[
S_{n+1}=S_n+X_n
\]

for the reference sequence:

\[
X=[3,5,2,7]
\]

with target:

\[
S=[3,8,10,17].
\]

This separates **computational expressivity** from **physical non-ideality**.

## Calibration configuration

For the first calibration:

- \(dt=1\,ns\)
- wave input gain = 1
- state-wave gain = 1
- wave retention = 0
- state feedback through the wave is disabled except for the input path
- noise = 0
- read back-action = 0
- nonlinearity = linear
- delay = 0

The remaining state equation is approximately:

\[
S_{n+1}=\lambda S_n+X_n
\]

where:

\[
\lambda=e^{-dt/\tau}.
\]

Therefore the ideal accumulator is approached as:

\[
\tau\rightarrow\infty
\]

and the finite-retention error is an explicit, measurable consequence of state decay.

## Why this matters

A failed result at short \(\tau\) must not be interpreted as failure of the computational primitive itself. It demonstrates that the chosen retention regime cannot preserve the required state accurately.

Conversely, a passing result establishes only that the mathematical abstraction has a feasible parameter region. It does not establish a physical device.

## Separation of evidence

### Established

Exponential decay and the relation:

\[
\lambda=e^{-\Delta t/\tau}
\]

are standard dynamical-system relations when first-order decay is an appropriate model.

### Mathematical deduction

For the accumulator:

\[
S_n=\sum_{k=0}^{n-1}\lambda^{n-1-k}X_k.
\]

At \(\lambda<1\), this is a leaky accumulator rather than an exact accumulator.

### Proposed synthesis

Use state lifetime as an explicit computational parameter and sweep it before selecting a physical material.

### Simulation result

Must be generated by the calibration runner. No experimental hardware result is implied.

## Acceptance

Calibration passes when relative RMS error is below 5% under ideal conditions.

Only after calibration passes should the full sweep introduce noise, delay, read disturbance and nonlinearities.

## Literature context

Recent photonic in-memory demonstrations reinforce the importance of separating memory retention, latency, noise and conversion overhead. They do not validate Horizon's proposed cell. For example, a 2026 Nature Communications demonstration explicitly analyzes retention-time-to-network-latency ratio and hardware non-idealities, while a 2026 Nature Sensors demonstration integrates long- and short-term memory with photonic computation. These are external benchmarks, not Horizon results.
